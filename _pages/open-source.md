I use open-source software and independent alternatives wherever practical. I have moved from Windows and macOS to Linux and now use [Arch Linux](https://archlinux.org/). I use [Signal](https://signal.org/) for messaging and [DuckDuckGo](https://duckduckgo.com/) for web searches.

[Fedora](https://fedoraproject.org/), [openSUSE](https://www.opensuse.org/), and [Manjaro](https://manjaro.org/) are other Linux distributions worth exploring. Open-source software and independent services are distinct: using an alternative service does not necessarily mean that its software is open source.

Avoiding proprietary services entirely is difficult, particularly on Android. This website itself is hosted on GitHub, which is owned by Microsoft. I see these limitations as reasons to make thoughtful choices and support the alternatives that are available.

For me, the case for these alternatives goes beyond privacy. I am concerned about how much power we give a small number of technology companies by depending exclusively on their software and services. Supporting independent alternatives is one way of responding to that concern.
